# Real iTero PLY fixture source

Real iTero-exported PLY case-media files (hundreds, 4–17 MB each) live in App/object storage under `${PRIVATE_OBJECT_DIR}/case-media/` — none exist on local disk (`uploads/case-media/` is empty in dev).

**Real iTero header layout** (the class synthetic test buffers miss):
- `binary_little_endian`, a `comment PLY generated by iTero software` line
- vertex props: `x y z` then `uchar red/green/blue` then `float nx ny nz` (color BETWEEN position and normals)
- face element declares `property int object` BEFORE `property list uchar int vertex_indices` — a scalar-before-list quirk that shifts binary offsets if the parser assumes list-first.

**Trimming to a checked-in fixture:** keep the exact header text (only rewrite the two element counts), copy the first N vertex records (stride = 27 bytes for the layout above), and keep only face records whose indices are all < N (record = 4-byte object + 1-byte count + count×4-byte indices). ~800 vertices → ~36 KB fixture. Checked in at `lib/scan-viewer/src/__fixtures__/itero-color-scan.ply`.

**Why:** synthetic PLY buffers previously missed layout combinations (gray-scan regression); a trimmed real file pins the true iTero layout without checking in megabytes or full patient scans.
