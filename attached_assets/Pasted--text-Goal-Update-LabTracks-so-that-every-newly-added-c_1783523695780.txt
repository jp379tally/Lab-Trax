Update LabTracks so that every newly added case item defaults to “Lab Only” visibility across all three platforms. This should apply to pictures/images, videos, uploaded files/attachments, notes, and any other case-added content that has a visibility/privacy/publication setting.

Right now, when a user adds media, files, or notes to a case, some items may default to public or to a broader visibility than intended. The desired behavior is privacy-first: new case content should be lab-only by default. Users can later choose to make an item public if the product allows that, but the initial default must always be Lab Only.

Likely root cause:
The default visibility is probably being set inconsistently across item creation flows. Some upload/note/media creation paths may omit the visibility field, rely on backend defaults, or use different frontend defaults per platform. The fix should centralize or consistently enforce the default at the creation boundary, not just in one UI screen.

   - visibility
   - privacy
   - accessLevel
   - isPublic
   - labOnly
   - audience
   - shareStatus
   - public/private flag

3. Set the default for new case content to Lab Only in the safest shared location.
